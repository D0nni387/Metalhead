# Metalhead

Resin collectible statue and figure painting portfolio.

Live preview: https://d0nni387.github.io/Metalhead/

## Structure

```
index.html
assets/
  css/style.css
  js/main.js
  images/*.webp
```

Run locally with `python3 -m http.server` from the repo root. Base: Metalhed V8.2 mobile preview.
